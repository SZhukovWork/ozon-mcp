# ozon-mcp

[English](README.md) · **Русский**

> Сервер для покупателя: читает публичную витрину как анонимный посетитель,
> аккаунт и токен Ozon не нужны. Для **кабинета продавца** (заказы, остатки,
> официальный Seller API) нужен другой инструмент.

[MCP](https://modelcontextprotocol.io)-сервер, который даёт LLM-агентам
актуальные данные с [Ozon](https://www.ozon.ru) и честно подписывает, что это
за данные. Есть поиск с настоящей пагинацией, сортировкой и ценовым окном;
карточки товаров, где подписана каждая цена, есть дата доставки в ваш регион,
юрлицо продавца, варианты и предложения других продавцов; отзывы, где
собственный рейтинг SKU отделён от рейтинга, который Ozon ставит на всю
линейку товаров.

## Зачем ещё один сервер для Ozon

Парсеры Ozon обычно отдают числа, которые выглядят правильно, а означают
другое. Этот сервер построен вокруг ловушек, найденных при сверке его ответов
с сайтом:

| Ловушка | Что делает сервер |
|---|---|
| Антибот Ozon (Variti) не пускает обычные HTTP-клиенты, даже с куками браузера (403/307) | Держит одну страницу Chromium на ozon.ru и вызывает API витрины изнутри неё; когда Ozon отзывает сессию, проходит проверку заново |
| Одна «цена» без пояснения, какая | Каждая цена названа: `price_with_ozon_card_rub` (при оплате картой Ozon Банка), `price_without_ozon_card_rub`, `price_before_discount_rub` (зачёркнутая). В плитках поиска есть только цена по Ozon Карте — это видно по имени поля |
| Рейтинг в карточке — это рейтинг всей **линейки вариантов**: у топора Fiskars 24 разные модели делят «4.9 • 3 536 отзывов» | Показывает рейтинг карточки с его охватом и рядом собственный рейтинг SKU, посчитанный по его отзывам (например, 4.94 по 389 отзывам); в поиске помечает общие рейтинги |
| «Бренд» берётся из первой метки плитки, а это часто «Бренд проверен» или «24 ₽ / шт» | Бренд — только если плитка его действительно показывает (иначе из структурированных данных карточки); цена за штуку идёт в `price_per_unit` |
| Нет пагинации; при сортировке по умолчанию на странице Ozon всего 8 товаров, и «limit 36» молча отдаёт 8 | Листает настоящие страницы выдачи, сообщает `next_page`, страницы не обрезает |
| Если идти по ссылке «следующая страница» дальше конца выдачи, Ozon бесконечно подгружает посторонние товары | Результатами считается только виджет результатов поиска |
| Фильтр и сортировка по цене у Ozon приблизительные (окно 1300–1450 ₽ отдаёт товары за 1058–1545 ₽) | Товары вне окна не выбрасываются, а помечаются `outside_price_window` |
| «Доставка сегодня», которая стоит +1 937 ₽ сверху | Обычная и платная экспресс-доставка — разные поля, с доплатой |
| Имя продавца обрезано вёрсткой карточки («Садовая техника и и...») | Полное имя, рейтинг, число заказов, юрлицо, ОГРН/ИНН и адрес |

В каждом ответе есть `fetched_at` и регион, для которого получены цены и даты.

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `search_products(query, page, sort, price_min, price_max, limit, auto_category)` | Целые страницы выдачи Ozon начиная с `page`, пока не наберётся `limit` товаров; сортировки `popular` / `price_asc` / `price_desc` / `rating` / `newest` / `discount`; `next_page`; `resolved_to` — категория и бренд, до которых Ozon сузил запрос. По товару: SKU, название, бренд (если показан), цена по Ozon Карте, зачёркнутая цена, метка скидки, цена за единицу, рейтинг и отзывы как на плитке + `rating_shared_with`, дата доставки (и платный экспресс с доплатой), остаток, продаёт ли сам Ozon, метка 18+, маркетинговые метки, ссылка |
| `get_product(product, include_variants, include_other_sellers, include_description)` | Все три цены; баннер распродажи и её срок; единственная подсказка Ozon об истории цены; наличие; способы доставки с датами, откуда везут, условия возврата; продавец с рейтингом, заказами и юрлицом; рейтинг карточки (охват, распределение звёзд) + собственный рейтинг SKU; все варианты с их SKU и ценами; предложения других продавцов того же товара; характеристики; описание; комплектация |
| `get_reviews(product, page, limit, sort, scope, include_seller_replies)` | По 30 на страницу; сортировки `helpful` (по умолчанию у Ozon) / `worst` / `best`; `scope=sku` или вся линейка (`line`); по отзыву: дата, оценка, текст, плюсы, минусы, к какому SKU и варианту он относится, число фото и видео, «полезно», `outdated`, число комментариев, ответ продавца (по запросу); распределение звёзд линейки и собственный рейтинг SKU |
| `compare_products(products, with_delivery)` | До 20 SKU: цены, наличие, рейтинг карточки с размером линейки, продавец, самое дешёвое предложение других продавцов, дата доставки |

`product` принимает SKU (`1837133915`) или ссылку на товар.

## Требования

| | |
|---|---|
| Python | ≥ 3.10 и [uv](https://docs.astral.sh/uv/) (или pip) |
| Браузер | Chromium для Playwright, скачивается сам при первом запуске (≈300 МБ загрузки, ≈650 МБ на диске в `~/.cache/ms-playwright`, общий для всех инструментов на Playwright). Антибот Ozon не пропускает обычный HTTP-клиент, поэтому каждый запрос делается изнутри страницы Chromium (headless shell): браузер открыт, пока сервер используется, и закрывается после 10 минут простоя. Первый запрос сессии занимает ≈15–35 с (запуск браузера и проверка антибота; замерено 34 с) |
| Docker | Не нужен: Chromium запускается как дочерний процесс сервера прямо в системе |
| Системные библиотеки | Уже есть в настольном Linux, macOS и Windows. На минимальном сервере Debian/Ubuntu поставьте их один раз (нужен root): `uvx --from playwright playwright install --with-deps chromium` |
| Сеть | Российский IP: VPN, зарубежные и многие датацентровые адреса блокируются. Выключите VPN или задайте `OZON_PROXY`. Кроме того, после многих новых сессий браузера за день Ozon может на время перестать пропускать IP (было при разработке) — тогда ждать, а не повторять, и не удалять каталог кеша: именно сохранённая сессия помогает проходить проверку |
| Память | ≈0,8 ГБ, пока открыт браузер (замер) |
| Дисплей | Не нужен (`OZON_HEADLESS=0` для отладки требует его) |
| Проверено на | Linux (CachyOS; Playwright ставит туда сборку для Ubuntu). macOS и Windows Playwright поддерживает, но там не проверялось |

## Установка

Claude Code:

```bash
claude mcp add ozon -- uvx --from git+https://github.com/SZhukovWork/ozon-mcp ozon-mcp
```

Любой MCP-клиент (`claude_desktop_config.json`, `.mcp.json` и т. п.):

```json
{
  "mcpServers": {
    "ozon": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/SZhukovWork/ozon-mcp", "ozon-mcp"]
    }
  }
}
```

Из клона репозитория: `uv venv && uv pip install -e . && .venv/bin/ozon-mcp`.

Первый запрос сессии открывает браузер и проходит антибот: это занимает
2–15 секунд (при самом первом запуске дольше — скачивается Chromium).
Дальше запрос идёт около секунды. После 10 минут простоя браузер
закрывается и открывается снова при следующем запросе.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `OZON_LOCATION` | — | Регион доставки. По умолчанию Ozon выбирает город по IP (он указан в каждом ответе). Можно задать город так, как он записан в адресах страниц Ozon `/geo/` (`moskva`, `ekaterinburg`, `sankt-peterburg`; сервер выберет первый пункт выдачи из списка Ozon для этого города), или ссылку на свой пункт выдачи, например `https://www.ozon.ru/geo/ekaterinburg/220380/` (откройте пункт на карте Ozon и нажмите «Поделиться»). Сервер выбирает пункт так же, как это делает анонимный посетитель сайта; если не получилось — в ответах будет `region.warning` |
| `OZON_PROXY` | — | Прокси для браузера, например `http://user:pass@host:3128` |
| `OZON_MIN_INTERVAL` | `1.0` | Пауза между запросами к Ozon, секунд |
| `OZON_IDLE_TIMEOUT` | `600` | Через сколько секунд простоя закрывать браузер |
| `OZON_HEADLESS` | `1` | `0` показывает окно браузера (для отладки) |
| `OZON_CACHE_DIR` | `~/.cache/ozon-mcp` | Где хранится сессия браузера (файлы с правами `0600`) |

## Что означают цифры

- **`price_with_ozon_card_rub`** — зелёная цена на сайте, «С банками»: при
  оплате картой Ozon Банка (Ozon указывает ещё несколько банков-партнёров).
  **`price_without_ozon_card_rub`** — «С другими банками», любая другая
  карта. **`price_before_discount_rub`** — зачёркнутая цена; её задаёт
  продавец, поэтому большие «скидки» от неё — маркетинг. В плитках поиска
  есть только цена по Ozon Карте (`price_rub` — у немногих товаров с
  единственной ценой).
- **Регион**: цены и даты зависят от региона (проверено: один и тот же топор
  стоил 8 453 ₽ в Екатеринбурге и 8 494 ₽ в Москве). Авторизованный
  покупатель может видеть другие цены.
- **Рейтинг**: `rating.shown_on_card` — то, что показывает сайт; `scope`
  говорит, относится ли он только к этому товару или к линейке из N
  товаров. `rating.this_sku` посчитан по отзывам самого SKU через фильтр
  Ozon «этот вариант»; `exact: false` — известна только нижняя граница.
  В поиске `rating_shared_with` перечисляет другие результаты с точно таким
  же рейтингом — это рейтинг линейки.
- **Доставка**: даты — те, что Ozon показывает для региона, переведённые в
  ISO-даты по часовому поясу региона (исходная формулировка сохранена в
  `text`). `express_delivery` / `express_surcharge_rub` — платная быстрая
  доставка Ozon.
- **Остаток**: `units_left` — только когда Ozon сам показывает счётчик
  («241 ед осталось»); внутренние лимиты корзины за остаток не выдаются.
- **Отзывы**: `date` — дата, которую показывает сайт (для изменённых
  отзывов — дата изменения). Ozon заявляет, что отзывы могут оставлять только
  купившие (`review_policy`); его отметка «Товар куплен на OZON» у отзывов
  почти не встречается, поэтому отсутствие `purchase_badge` не значит «не
  покупал». `outdated` — отзыв больше не учитывается в рейтинге. Имена
  покупателей не отдаются.
- **История цен**: у Ozon её нет. Если на карточке есть «Стало дешевле»,
  `get_product` отдаёт сравнение текущей цены (без Ozon Карты) со средней
  за прошлый месяц — и только это.

## Ограничения

- Неофициальный: использует внутренний composer API витрины, который Ozon
  может изменить в любой момент. Разбор ответов собран в `parse.py` и покрыт
  тестами на записанных ответах.
- Нужен российский IP: антибот Ozon отсекает VPN, зарубежные адреса и
  дата-центры. При необходимости — `OZON_PROXY`.
- Ozon не сообщает общее число найденных товаров; последняя страница
  становится известна, только когда следующая приходит пустой.
- Плитка поиска не называет продавца (только продаёт ли сам Ozon) — для
  этого `get_product` / `compare_products`.
- Товары 18+ (некоторые ножи, мачете) сайт показывает после подтверждения
  даты рождения; сервер не отправляет персональные данные от вашего имени:
  поиск помечает такие товары `adult_only`, инструменты карточки возвращают
  явную ошибку.
- Реклама: во время проверки Ozon не пометил рекламой ни одной плитки
  поиска; поле `sponsored` появится, только если плитка сама это скажет.
- Только чтение и только анонимно (см. «Планы»).

## Планы

- **Позже: необязательный режим аккаунта** (по умолчанию выключен). Один раз
  войти в видимом окне браузера — номер телефона и код из SMS не проходят
  через MCP-клиент — чтобы видеть свои персональные цены и точные даты
  доставки на свой адрес.
- **Позже: корзина** — `add_to_cart` / `get_cart` поверх режима аккаунта.
- Оформление заказа, оплата и смена адреса доставки в аккаунте — сознательно
  вне планов.

## Разработка

```bash
uv venv && uv pip install -e '.[dev]'
.venv/bin/pytest            # офлайн-тесты на записанных ответах
.venv/bin/pytest -m live    # сквозной прогон по MCP stdio против живого Ozon (нужен российский IP)
```

Устройство: `browser.py` (Chromium в своём потоке, антибот, регион),
`client.py` (политика запросов: повторная проверка, лимиты, регион),
`parse.py` (чистые функции над JSON Ozon), `server.py` (инструменты).

## Оговорка и благодарности

Проект не связан с Ozon. Предназначен для личного сравнения цен; соблюдайте
условия использования Ozon и не создавайте лишней нагрузки. Идея вызывать
composer API Ozon изнутри страницы браузера взята из
`eduard256/ozon-mcp-server` (Node.js, MIT); это независимая реализация.
